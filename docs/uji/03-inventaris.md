# 03 · Inventaris (Admin; Stok Opname juga Kasir)

- [ ] **Stok masuk dan konversi satuan**: buka Produk → **Stok Masuk** → pilih Amoxicillin → isi jumlah dalam satuan beli (mis. 2 box × 100) → no. batch, tanggal expired, catatan pemasok → simpan → coba produk wajib-expired tanpa tanggal expired → coba tanggal expired yang sudah lewat. **Hasil:** stok bertambah sesuai konversi, batch baru muncul di kartu stok, tanpa expired/expired lewat ditolak, Riwayat Stok mencatat mutasi MASUK.
- [ ] **FEFO dan blokir expired**: siapkan dua batch Amoxicillin (dekat expired dan jauh) → jual 60 tablet lewat Kasir sampai tagihan lunas → buka kartu stok Amoxicillin → ubah tanggal satu batch ke kemarin lewat data uji (atau tunggu) → coba jual dari stok yang tersisa hanya batch expired. **Hasil:** pengurangan mengambil batch expired-terdekat dulu (FEFO), lalu batch berikutnya; batch expired tidak terhitung stok jual dan Kasir menolak bila stok layak jual kurang.
- [ ] **Riwayat Stok**: buka Riwayat Stok → cari nama produk, no. batch, catatan → urutkan per waktu, produk, perubahan, jenis → klik nama produk → periksa paginasi. **Hasil:** semua mutasi (MASUK, KELUAR karena penjualan, KEMBALI karena pembatalan, ADJUST opname) tampil dengan tanda +/−, petugas, dan keterangan; klik produk membuka kartu stok.
- [ ] **Stok Opname lengkap (ulangi sebagai Kasir)**: buka Stok Opname → isi catatan sesi → **Mulai sesi baru** → periksa daftar batch dan kolom **Stok tercatat** → ubah hitung fisik satu batch lebih kecil, satu lebih besar, sisanya biarkan → coba finalkan tanpa alasan → isi alasan → simpan draft → keluar dan **Lanjutkan sesi draft** → finalkan. **Hasil:** produk tanpa stok tercantum di peringatan "tidak ikut dihitung"; finalisasi tanpa alasan ditolak; setelah final stok mengikuti hitung fisik, mutasi ADJUST tercatat, sesi berstatus Final dan tidak bisa diubah, kolom Selisih di daftar sesi sesuai.
- [ ] **Peringatan stok**: turunkan stok Amoxicillin di bawah batas minimum (jual atau opname) → buat batch yang expired dalam masa peringatan (Pengaturan → hari peringatan expired) → buka Dasbor, Notifikasi, Laporan Penjualan. **Hasil:** produk muncul di "Stok menipis" dan "Hampir expired", lonceng menampilkan jumlah belum dibaca, Kasir dan Dokter tidak menerima notifikasi stok.
