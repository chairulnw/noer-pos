# 01 · Akses, Login, dan Menu per Peran

- [ ] **Login gagal dan berhasil**: buka `/login` → isi username benar password salah → Masuk → isi username tidak terdaftar → Masuk → coba salah berulang (≥5 kali) → isi kredensial benar. **Hasil:** pesan gagal umum (tidak membocorkan mana yang salah), percobaan berulang dibatasi sementara, login benar membuka Dasbor.
- [ ] **Menu Admin lengkap**: login Admin → periksa sidebar grup demi grup (Ikhtisar, Penjualan, Operasional Klinik, Pelanggan, Inventaris & Ritel, Laporan, Data Master) → lipat dan buka setiap grup → klik setiap menu satu per satu. **Hasil:** menu persis: Dasbor · Kasir (POS), Transaksi (Lunas), Tagihan · Rekam Medis, Rawat Inap, Pet Hotel, Vaksin, Hasil Lab, Radiologi, Operasi, Grooming · Hewan Peliharaan, Pemilik Hewan, Deposit / Wallet · Produk, Riwayat Stok, Stok Opname, Biaya Operasional · Laporan Penjualan, Laba Rugi · Klinik, Jenis Hewan, Ras Hewan, Pengguna, Pengaturan Printer, Notifikasi, Profil. Tidak ada Janji Temu, Kehadiran, Tutup Kas, Kunjungan, Kandang di sidebar. Semua halaman terbuka tanpa error, menu aktif tersorot.
- [ ] **Menu Dokter terbatas**: login Dokter → periksa sidebar → coba buka manual `/kasir`, `/invoice`, `/pembayaran`, `/laporan`, `/laba-rugi`, `/biaya-operasional`, `/master-data/item`, `/pengguna`, `/pengaturan`, `/deposit`, `/audit`. **Hasil:** sidebar hanya Dasbor, Operasional Klinik (Rekam Medis s/d Grooming), Hewan Peliharaan, Pemilik Hewan, Notifikasi, Profil. Semua URL terlarang ditolak (dialihkan/403), tidak ada data yang bocor.
- [ ] **Menu Kasir terbatas**: login Kasir → periksa sidebar → coba buka `/rekam-medis`, `/vaksin`, `/hasil-lab`, `/radiologi`, `/operasi`, `/laporan`, `/laba-rugi`, `/biaya-operasional`, `/riwayat-stok`, `/inventaris/opname`, `/pengguna`, `/pengaturan`, `/audit`, `/master-data/kandang`. **Hasil:** Kasir melihat Penjualan, Rawat Inap, Pet Hotel, Grooming, Pelanggan (termasuk Deposit), Notifikasi, Profil. URL terlarang ditolak.
- [ ] **Kasir tidak melihat harga beli/omzet di mana pun**: sebagai Kasir buka Dasbor, Kasir (POS), detail tagihan, struk, PDF invoice, Produk (bila terbuka), Transaksi, Deposit → buka DevTools Network, periksa respons halaman. **Hasil:** tidak ada omzet hari ini, harga beli, HPP, margin, laba di tampilan maupun data respons.
- [ ] **Sesi dan profil**: sebagai tiap peran buka Profil → ganti password (isi lama salah dulu, lalu benar) → logout → login dengan password baru → kembalikan password. **Hasil:** password lama salah ditolak, yang baru berlaku, logout kembali ke login dan halaman dalam tidak bisa diakses lagi.
- [ ] **Pengguna nonaktif langsung terkunci**: Admin buka Pengguna → ubah Kasir menjadi Nonaktif sementara Kasir sedang login di jendela lain → Kasir klik menu apa saja → Admin aktifkan lagi. **Hasil:** Kasir langsung keluar/ditolak saat nonaktif, bisa login lagi setelah diaktifkan, perubahan tercatat di Audit Log.
