# 02 · Master Data (Admin)

- [ ] **Pengaturan Klinik terkunci dan bisa diubah**: buka Data Master → Klinik → coba klik/ketik di kolom → klik **Ubah data klinik** → ubah nama klinik, alamat, telepon, NPWP, unggah logo (PNG < 200 KB) dan coba logo > 200 KB → atur PPN aktif 11% mode tambahan → isi footer struk → ubah pilihan cepat SOAP (satu per baris) → Simpan → klik Ubah lagi, ubah sesuatu, klik **Batal**. **Hasil:** sebelum Ubah semua kolom nonaktif; logo besar ditolak; setelah Simpan muncul pesan sukses, kolom terkunci lagi, logo baru tampil di sidebar dan struk; Batal mengembalikan nilai semula; perubahan tercatat di Audit Log.
- [ ] **Pengaturan Printer**: buka Pengaturan Printer → pilih 58 mm → lihat pratinjau → klik Cetak halaman uji → ganti ke 80 mm → simpan → buka struk tagihan mana pun. **Hasil:** pratinjau mengikuti lebar terpilih, dialog cetak browser terbuka, struk memakai lebar tersimpan.
- [ ] **Jenis dan Ras Hewan**: buka Jenis Hewan → tambah "Kelinci" → coba tambah "kelinci" lagi → ubah nama → nonaktifkan → buka Ras Hewan → tambah ras "Holland Lop" untuk Kelinci → filter ras per jenis → cari "lop" → aktifkan lagi jenis Kelinci → buka form hewan baru. **Hasil:** duplikat (beda huruf besar/kecil) ditolak; jenis nonaktif tidak muncul di form hewan; ras muncul sebagai saran saat jenis Kelinci dipilih; kolom Jumlah ras bertambah.
- [ ] **Pengguna**: buka Pengguna → **+ Staf Baru** → buat dokter kedua (nama, username, password, peran Dokter) → coba username yang sudah ada → ubah peran menjadi Kasir → reset password → nonaktifkan → cari berdasarkan nama/username. **Hasil:** username duplikat ditolak, perubahan peran langsung mengubah menu pengguna itu, status Nonaktif tampil di tabel, semua tercatat di Audit Log. Admin tidak bisa menonaktifkan dirinya sendiri bila dibatasi.
- [ ] **Produk dan layanan**: buka Produk → **+ Produk/Layanan** → buat layanan (kategori konsultasi/tindakan/operasi/rawat inap/hotel/grooming, satuan per item atau per hari) dan produk (obat/vaksin/pet food/aksesoris, harga jual, harga beli, satuan dasar, satuan beli + konversi, batas stok minimum, wajib expired, interval vaksin untuk kategori vaksin) → coba kategori produk untuk layanan → ubah harga jual → nonaktifkan satu item → filter kelompok (PetShop, Obat & Resep, Vaksin, dst.) → cari via nama/SKU/barcode. **Hasil:** kategori tidak sesuai jenis ditolak, tidak ada kategori "consumable", item nonaktif tidak muncul di Kasir, perubahan harga tercatat di Audit Log, tabel menampilkan sisa stok dan batch FEFO.
- [ ] **Master Kandang (Pet Hotel)**: buka Pet Hotel → Master Kandang → **Tambah Kandang** → isi K-01, tarif 65.000, dimensi "Standar (60x50)", kategori Kucing, kapasitas 1 → simpan → buat juga K-02 (Kucing), D-01 (Anjing Kecil, 85.000) → coba nomor K-01 lagi → hapus kandang yang kosong → coba hapus kandang terisi (setelah skenario 07). **Hasil:** tarif tampil `Rp 65.000 / hari`, kode duplikat ditolak, kandang terhapus hilang dari grid tapi riwayatnya tetap, kandang terisi tidak bisa dihapus; tarif otomatis membuat layanan "Kandang K-01" per hari di Produk.
- [ ] **Master Kandang Rawat Inap**: buka `/master-data/kandang` (dari tombol di halaman Rawat Inap/Pet Hotel) → **+ Kandang Baru** jenis Rawat inap "RI-1" kapasitas 2 tarif 150.000 → ubah tarif → nonaktifkan lalu aktifkan → urutkan kolom tabel. **Hasil:** kandang muncul di pilihan check-in Rawat Inap saja, perubahan tarif mengubah harga layanan tertaut dan masuk Audit Log.
