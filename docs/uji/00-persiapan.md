# 00 · Persiapan

- [ ] **Siapkan lingkungan bersih**: jalankan `docker compose up -d db` → `pnpm prisma:migrate` → `pnpm prisma:seed` → `pnpm dev` (restart dev server setiap selesai migrasi) → buka `http://localhost:3000`. **Hasil:** halaman login tampil tanpa error, logo NOER muncul.
- [ ] **Siapkan tiga akun**: akun `admin`, `dokter`, `kasir` dari `prisma/seed.ts` (password lihat file seed, jangan dicatat di dokumen ini) → gunakan tiga browser/jendela private berbeda agar bisa berganti peran cepat. **Hasil:** ketiganya bisa login dan nama + peran tampil di pojok kiri bawah sidebar.
- [ ] **Siapkan data awal sebagai Admin** (dipakai skenario berikutnya): buat layanan *Konsultasi Umum* Rp 100.000, *Vaksin Rabies* (produk kategori vaksin, interval 365 hari) Rp 150.000, *Amoxicillin 500mg* (produk obat, satuan tablet, batas stok minimum 20) Rp 2.000/tablet, *Royal Canin Kitten 400g* (pet food) Rp 85.000, *Kalung Kucing* (aksesoris) Rp 25.000, layanan *Mandi Kucing* (grooming) Rp 60.000, layanan *Sterilisasi Kucing* (operasi) Rp 750.000, layanan *Rawat Inap Standar* (rawat inap, per hari) Rp 150.000 → stok masuk Amoxicillin 2 batch (A1 expired 2 bulan lagi 50 tablet, A2 expired 1 tahun lagi 100 tablet), Vaksin Rabies 10, Royal Canin 10, Kalung 15. **Hasil:** semua item muncul di Produk dengan stok sesuai.
- [ ] **Pastikan pengaturan PPN diketahui**: buka Data Master → Klinik, catat apakah PPN aktif dan modenya (termasuk/tambahan). **Hasil:** semua perhitungan total di skenario lain disesuaikan dengan pengaturan ini.
- [ ] **Uji otomatis sebagai pembanding** (opsional, menghapus data transaksi dev): `pnpm lint && pnpm test && pnpm e2e`. **Hasil:** semua lulus. Setelah e2e, ulangi langkah data awal.
