# 09 · Tampilan Tabel, Filter, dan Responsif

- [ ] **Pola tabel di semua daftar**: buka satu per satu Tagihan, Transaksi, Rekam Medis, Vaksin, Hasil Lab, Radiologi, Operasi, Grooming, Rawat Inap, Hewan Peliharaan, Pemilik, Deposit, Produk, Riwayat Stok, Stok Opname, Biaya Operasional, Jenis Hewan, Ras Hewan, Pengguna, Master Kandang → di tiap halaman ganti Baris 10/25/50, pindah halaman dengan panah, klik muat ulang. **Hasil:** tabel mengisi tinggi layar, header kolom menempel saat digulir, footer "Menampilkan a - b dari n data" dan "Total: n Data" benar.
- [ ] **Tabel kosong tetap berkolom**: cari kata acak di setiap daftar di atas. **Hasil:** header kolom tetap tampil, pesan kosong di bawah header.
- [ ] **Urutkan kolom**: di setiap daftar klik judul kolom yang punya ikon panah → klik lagi → pindah halaman → cari sesuatu. **Hasil:** urutan naik lalu turun berlaku untuk seluruh data (bukan hanya halaman ini), panah aktif menunjukkan arah, urutan tetap saat pindah halaman/ganti jumlah baris/mencari.
- [ ] **Filter ringkas**: di Tagihan, Operasi, Grooming, Rekam Medis, Deposit, Vaksin, Hasil Lab, Radiologi ubah dropdown di samping kolom cari. **Hasil:** filter langsung diterapkan tanpa tombol Terapkan, tidak ada dua date picker, kombinasi filter + cari + sort tetap bekerja.
- [ ] **Format angka dan waktu**: periksa seluruh layar uang (tabel, kartu, struk, PDF, input nominal) dan waktu. **Hasil:** uang `Rp 1.000`, input nominal otomatis bertitik ribuan, tanggal/jam WIB dan berbahasa Indonesia.
- [ ] **Tampilan HP dan tablet**: perkecil browser ke lebar 375 px dan 768 px → buka Dasbor, Kasir, Pet Hotel, form check-in, Hewan Peliharaan, profil hewan, rekam medis → buka/tutup sidebar. **Hasil:** tidak ada gulir horizontal halaman (tabel boleh gulir sendiri), tombol mudah disentuh, dialog muat di layar.
