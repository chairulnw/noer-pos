# 05 · Alur Klinik (Dokter)

- [ ] **Buat kunjungan dari profil hewan (Kasir/Dokter)**: buka profil hewan → **+ Buat kunjungan** → pilih dokter → isi keluhan → simpan → buka Dasbor sebagai Dokter. **Hasil:** kunjungan berstatus Dilayani, muncul di antrean "Pasien menunggu diperiksa" Dokter (auto refresh), dan di Rekam Medis berstatus "Belum diisi".
- [ ] **Isi rekam medis SOAP sampai final**: sebagai Dokter buka Rekam Medis → filter status "Belum diisi" → **Periksa** → isi vital (suhu, HR, RR, berat, CRT, dst.) → gunakan **Pilih cepat** untuk Subjective/Objective/Assessment/Plan → isi diagnosis → tambah item resep/tindakan (obat dengan jumlah + aturan pakai, layanan konsultasi) → **Simpan draft** → keluar → buka lagi → **Finalkan** → konfirmasi. **Hasil:** draft tersimpan dan bisa diubah; setelah final semua kolom terkunci, berat badan terakhir pasien ikut diperbarui, status berubah Final, item masuk ke tagihan draft kunjungan untuk Kasir, kunjungan pindah ke "Menunggu pembayaran" di Dasbor Kasir.
- [ ] **Rekam medis final tidak bisa diubah, koreksi via addendum**: buka rekam medis Final → pastikan tidak ada tombol simpan/ubah → coba kirim ulang form lama (tombol kembali browser) → tulis **Addendum** koreksi diagnosis → simpan → unggah lampiran PDF/JPG/PNG → coba unggah file .docx atau > 10 MB. **Hasil:** perubahan langsung ditolak, addendum tampil dengan nama dokter dan waktu WIB, lampiran valid bisa dibuka, file salah ditolak, semua tercatat di Audit Log.
- [ ] **Vaksinasi**: di rekam medis kunjungan catat vaksin (Vaksin Rabies, no. batch, tanggal) → biarkan tanggal ulang otomatis (interval item) atau isi manual → hapus lalu catat lagi selama masih draft → finalkan → buka Vaksin tab **Riwayat Vaksinasi** → cari nama/batch → pilih **Periode** "Bulan ini" → buka tab **Jatuh Tempo** → pilih 7/14/30 hari. **Hasil:** satu dropdown periode (bukan dua tanggal); vaksin ulang = tanggal + interval; vaksin jatuh tempo muncul di tab Jatuh Tempo, Dasbor, dan Notifikasi; yang lewat tanggal ditandai "lewat".
- [ ] **Hasil Lab**: buka Hasil Lab → **+ Hasil Lab** → pilih pasien dari daftar (tanpa harus mengetik) → kaitkan ke rekam medis kunjungan (opsional) → isi nama pemeriksaan, tanggal, hasil/nilai, catatan → unggah lampiran → simpan → ubah → cari dan filter periode → buka dari profil hewan. **Hasil:** hasil tampil di daftar, profil hewan, dan rekam medis terkait; lampiran bisa dibuka; Kasir tidak bisa membuka halaman ini.
- [ ] **Radiologi**: ulangi alur Hasil Lab di menu Radiologi (X-Ray/USG, temuan/interpretasi, unggah gambar). **Hasil:** sama seperti Hasil Lab, label kolom memakai istilah radiologi.
- [ ] **Operasi lengkap**: buka Operasi → **+ Jadwal Operasi** → pilih pasien dari daftar → isi prosedur, tanggal, dokter operator, anestesi, layanan Sterilisasi Kucing, catatan pra-operasi → simpan → **Ubah** jadwal → **Mulai operasi** → coba **Selesaikan** tanpa catatan pasca-operasi → isi catatan → Selesaikan → konfirmasi → buka tagihan dari detail → tambah **Addendum** → buat operasi kedua lalu **Batalkan** sebelum selesai → filter status di samping cari. **Hasil:** status hanya maju (Dijadwalkan → Berjalan → Selesai), tanpa catatan pasca ditolak, selesai membuat tagihan draft atas nama pemilik berisi layanan operasi, data terkunci setelah selesai (koreksi via addendum), operasi batal tidak membuat tagihan, Kasir tidak bisa membuka Operasi.
- [ ] **Dokter tidak mengurus uang**: sebagai Dokter buka rekam medis final dan detail operasi → cari tautan ke tagihan/kasir → buka Dasbor. **Hasil:** tidak ada tautan tagihan/harga, Dasbor Dokter hanya tab Kunjungan pada Tren Statistik, tanpa omzet/operasional.
