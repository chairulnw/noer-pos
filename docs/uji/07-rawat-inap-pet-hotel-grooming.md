# 07 · Rawat Inap, Pet Hotel, Grooming

- [ ] **Rawat inap dengan monitoring**: Dokter buka profil hewan → **Check-in** (atau Rawat Inap → + Check-in) → pilih pasien dari daftar → pilih kandang RI-1, tarif harian, kaitkan ke kunjungan hari ini → isi catatan → simpan → buka **Monitoring** → tambah log (suhu, makan/minum, catatan) beberapa kali → coba log kosong → buka profil hewan. **Hasil:** pasien tampil di daftar Rawat Inap dengan "Hari ke-n", log terurut waktu WIB, log kosong ditolak, monitoring terakhir tampil di profil, Kasir hanya bisa check-out (tanpa monitoring).
- [ ] **DP rawat inap lalu check-out**: Kasir buka tagihan rawat inap (menu ⋯ Invoice) → terima DP → Dokter tambah obat ke tagihan → **Check-out** dengan waktu keluar 2 hari setelah masuk → periksa pratinjau "Lama menginap" → konfirmasi → bayar sisa. **Hasil:** jumlah hari = tanggal keluar − tanggal masuk (minimal 1), item tarif × hari masuk tagihan, sisa = total − DP, pasien hilang dari daftar aktif, waktu keluar di masa depan ditolak.
- [ ] **Kapasitas kandang**: atur RI-1 kapasitas 2 → check-in 2 pasien berbeda → coba check-in pasien ketiga → coba turunkan kapasitas jadi 1 → check-out satu pasien. **Hasil:** kandang penuh tidak muncul di pilihan dan ditolak, kapasitas di bawah jumlah penghuni ditolak, satu pasien yang sama tidak bisa menginap di dua kandang.
- [ ] **Pet Hotel: ringkasan dan check-in boarding**: buka Pet Hotel → periksa 4 kartu (Total Kandang, Tersedia, Sedang Terisi, Perlu Sanitasi) → **Check-In Boarding** → pilih pasien lewat kotak cari (daftar tampil saat diklik) → pilih slot kandang (kotak; yang Dibersihkan/Terisi/tanpa tarif tidak bisa dipilih) → tanggal check-in, estimasi check-out sebelum check-in (harus ditolak) lalu benar → isi instruksi pakan & jadwal makan + catatan obat bawaan → **Simpan & Check-In Pasien**. **Hasil:** kembali ke Pet Hotel tab **Pasien Menginap** dengan kartu berisi pemilik, badge kandang, tanggal masuk, estimasi keluar, durasi berjalan (n hari × tarif), estimasi tagihan; kartu ringkasan berubah.
- [ ] **Pet Hotel: detail, check-out, sanitasi**: pada kartu pasien klik **Edit Detail** → pastikan instruksi pakan, estimasi keluar, catatan obat tampil → kembali → **Check-Out & Kasir** → konfirmasi → bayar tagihan → buka tab **Grid Kandang** → kandang berstatus **Dibersihkan** → coba check-in ke kandang itu → klik **Tandai bersih** → buka tab **Riwayat Check-Out**. **Hasil:** kandang kotor tidak bisa dipakai sampai ditandai bersih (Kasir juga boleh menandai), status kembali Tersedia, riwayat menampilkan pasien • kandang • tanggal check-out + tautan tagihan (Admin/Kasir).
- [ ] **Pet Hotel: master dan pencarian**: buka **Master Kandang** → gunakan Set Dibersihkan / Set Tersedia → hapus kandang kosong → di halaman utama cari nama pasien, pemilik, nomor kandang di setiap tab. **Hasil:** status kandang berubah di grid dan kartu ringkasan, pencarian bekerja di ketiga tab, Dokter/Kasir tidak melihat tombol tambah/hapus (Admin saja).
- [ ] **Grooming**: buka Grooming → **+ Grooming Baru** → pilih pasien → pilih layanan Mandi Kucing, tanggal, catatan (kutu/bulu kusut) → simpan → **Mulai grooming** → **Selesaikan** → konfirmasi → buka tagihan dari detail (Admin/Kasir) → bayar → buat grooming kedua lalu **Batalkan** → gunakan dropdown status di samping cari dan urutkan kolom. **Hasil:** status Menunggu → Proses → Selesai, selesai membuat tagihan draft pemilik berisi layanan grooming, batal tidak membuat tagihan, semua peran bisa mengerjakan grooming, tanpa layanan kategori grooming muncul petunjuk menambah di Produk.
