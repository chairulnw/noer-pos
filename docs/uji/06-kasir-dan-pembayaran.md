# 06 · Kasir dan Pembayaran

- [ ] **Penjualan retail walk-in tunai**: Kasir buka Kasir (POS) → periksa tata letak penuh layar (katalog kiri, keranjang kanan, tanpa judul halaman) → pilih kelompok **PetShop**, lalu **Obat & Resep** → ganti tampilan kotak/daftar → cari "royal", scan/ketik barcode lalu Enter → klik + Royal Canin dan Kalung → ubah jumlah dengan −/+ dan ketik langsung → hapus satu baris → biarkan pelanggan "Umum / Walk-in" → **Bayar (Rp …)** → metode Tunai → pilih tombol uang cepat → lihat kembalian → Bayar. **Hasil:** keranjang kosong menampilkan placeholder di tengah, Total Kuantitas dan Total Tagihan benar (termasuk PPN bila aktif), kembalian benar, layar selesai menampilkan total + kembalian, transaksi pindah ke **Transaksi (Lunas)**, stok berkurang (FEFO).
- [ ] **Diskon baris dan diskon keranjang**: di Kasir tambah 2 produk → diskon baris persen 10% → diskon baris nominal 5.000 (input tampil berformat ribuan) → **Diskon Cart → + Tambah Diskon** nominal 10.000 → ubah ke persen → coba persen > 100 → bayar. **Hasil:** semua diskon dihitung benar dan tercetak di struk, persen > 100 ditolak, diskon tercatat di Audit Log.
- [ ] **Pelanggan terdaftar dan pembayaran saldo**: di Kasir pilih pelanggan (pemilik yang punya saldo dari skenario 04) → tambah produk → Bayar → pilih metode **Saldo** → coba saat saldo kurang → kurangi item → bayar. **Hasil:** metode Saldo hanya muncul bila ada pemilik, saldo kurang ditolak, saldo terpotong sesuai total, mutasi PEMAKAIAN tercatat di Deposit.
- [ ] **Metode non-tunai**: bayar tiga transaksi dengan QRIS (gambar QRIS klinik tampil bila sudah diunggah), Transfer (isi referensi), Kartu (4 digit + no. approval). **Hasil:** metode tersimpan dan tampil di kolom Metode bayar Transaksi, tidak masuk hitungan kas tunai.
- [ ] **Tagihan dari kunjungan dokter**: setelah Dokter finalkan rekam medis (skenario 05) → Kasir buka Dasbor → **Menunggu pembayaran** → **Buka invoice** → periksa item dari rekam medis → klik **Lihat katalog di Kasir** → tambah produk pet food → kembali → bayar lunas → cetak struk. **Hasil:** tagihan draft bisa ditambah item, nama pasien/pemilik terkunci, setelah lunas status kunjungan Selesai dan hilang dari antrean.
- [ ] **DP lalu pelunasan**: buat tagihan draft (kunjungan atau Kasir dengan pelanggan) → di dialog bayar klik **Bayar DP** → isi DP tunai sebagian → simpan → tambah item lagi → buka Tagihan → periksa kolom Sisa tagihan dan chip DP → bayar sisa. **Hasil:** DP tercatat tanpa memfinalkan tagihan, sisa = total − DP, pelunasan memfinalkan tagihan dan mengurangi stok, tagihan pindah dari Tagihan ke Transaksi (Lunas).
- [ ] **Koreksi DP (Admin)**: buka tagihan yang punya DP → koreksi nominal DP → coba koreksi DP yang dibayar dengan Saldo. Sebagai Kasir cari tombol koreksi. **Hasil:** koreksi DP tunai berhasil + Audit Log, DP dari Saldo ditolak (harus lewat pembatalan), Kasir tidak punya akses.
- [ ] **Pembatalan tagihan (Admin)**: buka tagihan lunas berisi obat dan yang dibayar dengan Saldo → menu ⋯ → **Batalkan invoice** → isi alasan < 3 karakter lalu alasan valid → pilih kembalikan stok obat → konfirmasi. Sebagai Kasir cari menu pembatalan. **Hasil:** tidak ada kata "Void" di layar; status menjadi **Dibatalkan**, pembayaran dicoret, stok yang dipilih kembali (mutasi KEMBALI), saldo deposit kembali, tagihan hilang dari Transaksi dan muncul di Tagihan dengan filter Dibatalkan, Kasir tidak punya menu ini, tercatat di Audit Log.
- [ ] **Tagihan menunggu**: di Kasir isi keranjang untuk pelanggan A (jangan bayar) → **Transaksi baru** → isi keranjang pelanggan B → buka **Tagihan menunggu** di header katalog → pilih tagihan A → lanjutkan bayar. **Hasil:** draft A tersimpan dan bisa dilanjutkan, nomor invoice tampil di subjudul Keranjang.
- [ ] **Daftar Tagihan**: buka Tagihan → pastikan tidak ada tagihan lunas → gunakan dropdown status (Semua/Draft/Dibatalkan) di samping cari → cari no. invoice/pasien/pemilik → urutkan nomor, tanggal, total, status. **Hasil:** hanya draft (termasuk DP) dan dibatalkan, kolom Sisa tagihan benar.
- [ ] **Transaksi (Lunas), struk, dan PDF**: buka Transaksi → cari, urutkan waktu/nomor/total → klik **Struk** → cetak (58/80 mm) → klik **Invoice PDF** → buka PDF. **Hasil:** satu baris per tagihan lunas dengan metode bayar, struk berisi nama klinik, logo, item, diskon, PPN, pembayaran, kembalian, footer; PDF berisi kop klinik, pasien, tabel item, total, tanpa harga beli.
